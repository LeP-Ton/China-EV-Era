# 车标与车头融合返修

## 背景与目标

- 用户反馈车头车标效果突兀，截图中的深色圆角底牌像贴在引擎盖上的按钮，要求与车头融合。
- 当前聊天会话-26 起，创建时间：2026-11-11 08:35:14，Asia/Shanghai。
- 基线：`main` / `3756cbd`，本地与远程一致，工作区干净。
- 目标：使用符合车辆比例的小尺寸银色金属徽记，让位置、表面透视、反光及接触阴影与引擎盖一致。

## 约束与原则

- 复用当前高分辨率透明车辆素材和六款原创车标。
- 开局、驾驶舱及研发页共用同一车头徽记组件。
- 保持选择、企业图标、存档兼容与经营模拟行为一致。

## 关键实现与风险

- 底牌移除，金属反射只覆盖图案本身，车漆可从图案周围及内部镂空处自然呈现。
- 透视矩阵按当前 1774×887 原图的引擎盖平面标定；替换车辆素材时需要重新校准。
- 金属渐变与阴影滤镜使用 React 实例唯一 ID，防止多车同时展示时串用材质。
- 小屏下徽记尺寸接近实际车标比例，需要核对清晰度、抗锯齿和反光强度。
- 视觉验收需要查看实际图片，交互测试通过不能替代用户审美确认。
