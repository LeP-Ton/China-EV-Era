## 当前有效结论

- 本地独立运行；React/TypeScript/Vite；引擎纯函数优先，统一种子随机源；不调用外部 AI 或在线服务。
- 一个当前车型项目，技术为电池/智驾/安全；三名高管兼管研发、财务、制造与质量，营销按战略预算自主执行。
- 内部金额使用百万元；市场为虚构、可比较的中国新能源细分市场，所有参数是游戏规则，不宣称预测真实行业。
- 财务区分现金、利润、库存、资本支出与融资；生产批次保存实际交付队列，耐久风险按车主使用年限暴露。
- 三家对手受同一消费者选择、有限资金、有限授信、产线施工和固定费用规则约束；其内部车型与质量管理在 MVP 中简化。
- 存档保存随机数内部状态；复盘从原始开局重放重大决策，核对经营状态与财务流水。
- 日期使用 Asia/Shanghai；首版经营 2026—2028 年。
